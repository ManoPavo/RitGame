# RitGame

Projeto de jogo de ritmo em Godot com uma estrutura mais limpa e sem dependência de Python.

## O que foi organizado

- O menu agora leva direto para a fase principal.
- Arquivos e scripts relacionados à análise externa via Python foram removidos.
- A estrutura ficou mais focada nos recursos do jogo.

## Estrutura principal

- [scenes](scenes) - cenas do jogo
- [scripts](scripts) - lógica do jogo
- [assets](assets) - sprites, música e elementos visuais
- [addons](addons) - complementos úteis do projeto

## Como usar

1. Abra o projeto no Godot.
2. Execute a cena principal.
3. Jogue normalmente, sem necessidade de instalar Python.
